## Notes

- **Terminology Priority**: Community convention → Official translations (if available) → Mainland CN conventions (as fallback)
- **Taiwan Preferences**:
  - Use "遊戲" for "game" (system/product), "比賽" for competitive context
  - Prefer "設定" over "設置" for settings/options
  - Use traditional punctuation (、，；。) consistently
- **Brand Names**: Keep English names for Black Book, card games, NPCs (unless officially translated)
- **Consistency**: All instances of a term must use the same TC translation
