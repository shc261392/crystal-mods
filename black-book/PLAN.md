# Mod plan: Black Book

> Status: **draft** (post-discovery, pre-implementation).
> Discovery report: [`DISCOVERY.md`](DISCOVERY.md).

## Game profile

- **Engine:** Unity `2018.4.31f1`, scripting backend **Mono**.
- **Install size:** 2.2 GB / 7932 files.
- **Steam AppID:** `1138660`.
- **Linux/Proton:** untested; Mono Unity 2018 games typically run cleanly under Proton.

## Key finding from discovery

**XUnity AutoTranslator + ReiPatcher are already installed** in this Steam
copy (presumably by a previous user session). A `zh-TW` translation dump
exists at:

```
AutoTranslator/Translation/zh-TW/Text/_AutoGeneratedTranslations.txt   (555 KB)
```

That dump is auto-generated machine translation. Our mod can build on top of
it rather than start from scratch.

## Goal

User intent: *"convert via opencc"*.

Concrete deliverable: a zh-TW localisation mod for Black Book that ships
either (a) an upgraded XUnity AutoTranslator translation file converted /
hand-polished from the in-game zh-CN community pack, or (b) a fresh full
translation produced by the upcoming repo-wide translation tool.

## Strategy options

### Option A — OpenCC-only quick pass

1. Locate an existing high-quality Simplified Chinese (zh-CN or zh-Hans) translation file for Black Book (community fan TL on the Steam forum / NGA / Bilibili).
2. Run [OpenCC](https://github.com/BYVoid/OpenCC) `s2twp.json` to convert SC → TC (Taiwan, with phrase substitution).
3. Drop the resulting file in `AutoTranslator/Translation/zh-TW/Text/_AutoGeneratedTranslations.txt` of the mod payload.
4. Ship as a Vortex / manual install package: copies `AutoTranslator/` and `BepInEx/` (or ReiPatcher) into the game root.

Pros: ships in days. Cons: SC source quality bounds output quality.

### Option B — Repo translation tool

Once `tools/python/translation-tool` exists (planned), feed the EN strings
through it with a curated glossary and Gemini Flash. Output the same
AutoTranslator format. Higher quality, longer lead time.
