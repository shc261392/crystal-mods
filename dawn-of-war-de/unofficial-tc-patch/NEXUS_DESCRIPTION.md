## Full Description

Unofficial Traditional Chinese localization patch for Warhammer 40,000: Dawn of War – Definitive Edition.

IMPORTANT UPDATE: The official game patch 2.9.0 (released June 24, 2026) fixed the extremely small font size issue in the Chinese locale. This mod now focuses purely on translation quality and font coverage, without modifying font sizes.

What This Mod Does:
- Replaces the game's Simplified Chinese translation with Traditional Chinese
- Provides full Traditional Chinese glyph coverage using Noto Sans TC fonts
- Corrects translation errors and improves text quality in Engine.ucs
- Uses vanilla font sizes (no modifications)

Installation:
1. Download the mod zip file
2. Install the Vortex extension for this game (required, see Files tab)
3. Add the mod to Vortex
4. Deploy mods
5. Launch the game and select Chinese language

The mod works by replacing files in Engine/Locale/Chinese/ directory. Vortex automatically handles backups and deployment.

Manual Installation (without Vortex):
Extract the mod zip to your game's Engine/Locale/Chinese/ folder. That's it.

To Uninstall:
- With Vortex: Click "Purge Mods"
- Manual: Delete EnginLocMod.sga and Engine.ucs from Engine/Locale/Chinese/

Requirements:
- Warhammer 40,000: Dawn of War – Definitive Edition (Steam)
- Game version 2.9.0 or later recommended
