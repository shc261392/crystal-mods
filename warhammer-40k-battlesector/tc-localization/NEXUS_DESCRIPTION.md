# Nexus Mods Description — Battlesector Traditional Chinese Localization

## Short Description (max 250 chars)
Traditional Chinese (繁體中文) localization for Warhammer 40,000: Battlesector. Replaces Simplified Chinese slot. Select "Chinese (Simplified)" in-game to display Traditional Chinese.

---

## Full Description

**繁體中文 Traditional Chinese Localization**

Community Traditional Chinese (繁體中文) localization mod for Warhammer 40,000: Battlesector.

本模組為《戰鎚40,000：Battlesector》的社群繁體中文化補丁。

---

**How It Works 運作方式**

This mod replaces the Simplified Chinese (SC) locale slot in the game's asset files with Traditional Chinese text. 

本模組將遊戲資源檔案中的簡體中文欄位替換為繁體中文文字。

To use: Launch the game → Settings → Language → Select "Chinese (Simplified)"

使用方法：啟動遊戲 → 設定 → 語言 → 選擇「Chinese (Simplified)」

The mod directly patches sharedassets1.assets binary file - no external mod loader required.

模組直接修補 sharedassets1.assets 二進位檔案，無需額外的模組載入器。

---

**Known Limitations 已知限制**

Some text will display as boxes (口口口) due to font limitations:
- Campaign descriptions (戰役描述)
- Crusade mode story text (聖戰模式劇情文字)
- Some UI elements (部分介面元素)

某些文字會因字型限制而顯示為方框（口口口）：
- 戰役描述
- 聖戰模式劇情文字
- 部分介面元素

However, the important gameplay text works correctly:
- Unit names and descriptions (單位名稱與說明)
- Abilities and weapons (技能與武器)
- Combat interface (戰鬥介面)
- Most menu text (大部分選單文字)

重要的遊戲文字皆正常顯示：
- 單位名稱與說明
- 技能與武器
- 戰鬥介面
- 大部分選單文字

This is a technical limitation of the TextMesh Pro font assets. The core gameplay experience is fully translated.

這是 TextMesh Pro 字型資源的技術限制。核心遊戲體驗已完整翻譯。

**Installation 安裝方式**

Option A - Vortex (Recommended 建議)
1. Install the Battlesector Vortex extension (required, see Files tab)
   安裝 Battlesector Vortex 擴充套件（必要，請見檔案分頁）
2. Drag this mod zip onto Vortex
   將此模組壓縮檔拖入 Vortex
3. Click "Deploy Mods"
   點選「Deploy Mods」
4. Launch game and select Chinese (Simplified) in language settings
   啟動遊戲並在語言設定中選擇 Chinese (Simplified)

Option B - Manual Installation 手動安裝
1. Backup your Warhammer 40K Battlesector_Data/sharedassets1.assets file
   備份您的 Warhammer 40K Battlesector_Data/sharedassets1.assets 檔案
2. Extract mod files to game installation directory
   解壓縮模組檔案至遊戲安裝目錄
3. Launch game and select Chinese (Simplified)
   啟動遊戲並選擇 Chinese (Simplified)

To Uninstall 解除安裝:
- Vortex: Click "Purge Mods" (restores backup automatically)
  Vortex：點選「Purge Mods」（自動還原備份）
- Manual: Restore your backed-up sharedassets1.assets file
  手動：還原您備份的 sharedassets1.assets 檔案
