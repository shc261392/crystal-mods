# Battlesector Tools

Web tools for Warhammer 40,000: Battlesector — unit & weapon database, army
list builder, damage calculator, and unit comparison. Built from game data
extracted out of the Unity asset bundles.

## Stack

- **Framework**: Astro 5 (`output: 'static'` — every page prerendered)
- **Deployment**: Cloudflare Workers (static assets via `wrangler deploy --assets`)
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Language**: TypeScript (strict mode, `noUncheckedIndexedAccess`)
- **Linter/Formatter**: Biome

Every unit and weapon has its own statically-rendered, directly-linkable page
(e.g. `/units/1006-tyranid-termagant`, `/weapons/40-thunder-hammer`).
Interactive tools run entirely client-side, so the whole site is static and
edge-cacheable.

## Development

```bash
# Install dependencies (from repo root — this app is a pnpm workspace member)
pnpm install

# Start dev server
cd warhammer-40k-battlesector/battlesector-tools
pnpm dev

# Type-check + build (outputs static dist/)
pnpm build

# Preview the production build
pnpm preview

# Lint / format
pnpm lint
pnpm format

# Deploy to Cloudflare Worker (serving static assets from dist/)
pnpm deploy
```

## Features

- **Unit Database** (`/units`) — all 190 units with full stats. Instant
  client-side search, faction/role filters and sorting, all synced to the URL
  so any filtered view is shareable.
- **Weapon Database** (`/weapons`) — all 442 weapons with damage/accuracy,
  per-weapon damage-vs-armor tables and the units that carry them.
- **Army Builder** (`/army-builder`) — compose a list with live point totals
  and faction breakdown, saved to `localStorage` and shareable via a compact
  `?ids=` URL.
- **Damage Calculator** (`/calculator`) — models damage vs armor, hit chance and
  expected casualties using the extracted in-game formulas. Preload a matchup
  with `?weapon=<id>&unit=<id>`.
- **Unit Comparison** (`/compare`) — up to four units side by side with the best
  value per stat highlighted. Shareable via `?ids=`.
- **Command palette** — `⌘K` / `Ctrl+K` global search across units and weapons.
- Fully responsive, mobile-first, dark grimdark theme.

## Data pipeline

Source data lives in `src/data/` (`units.json`, `weapons.json`,
`factions.json`, `roles.json`, `summary.json`) plus `public/search-index.json`.
These are generated by `prepare_website_data.py` in
`../../.copilot_workspace/battlesector-data/`, which resolves all localization
IDs (faction names, role names/colours, weapon names in loadouts) from the
extracted text repositories.

To regenerate after a new extraction:

```bash
python3 ../../.copilot_workspace/battlesector-data/prepare_website_data.py
```

The combat formulas (`src/lib/combat.ts`) are documented in the data-mining
analysis under `../../.copilot_workspace/battlesector-data/`.

## Research source policy (truth-grounding)

When extending mechanics or localization logic, use this precedence:

1. Extracted game data/tables/text under `../../.copilot_workspace/battlesector-data/`
2. zh-TW TC mod source under `../tc-localization/translation/zh-TW/source/zh-TW/`
3. Official manual PDF `../../.copilot_workspace/battlesector-data/Battlesector_manual_EBOOK.pdf`

If any conflict appears, **extracted data overrides manual wording**.
Manual content is a conceptual aid, not a higher-priority numeric source.
