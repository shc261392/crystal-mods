# Red Laser Lasgun

Turns the **Astra Militarum lasgun into a glowing red laser beam** in Warhammer
40,000: Battlesector — a proper lance of light from muzzle to target, instead of
a little flying bolt. **Zero side effects** on other weapons.

## Requires

- **BepInEx Framework** (the BepInEx 6 IL2CPP runtime). Install it first, launch
  the game once, then install this.

## What you get

- A per-shot **glowing red beam** (bright core + soft glow halo) from every AM las
  weapon: Lasgun, Hot-Shot, Las Pistol, Multilaser and Lascannon.
- The old flying bolt is hidden so you just see the laser.
- Nothing else changes — the beam is drawn with the plugin's own light/colour, so
  no other weapon or effect is touched, and no game files are modified.

## Tuning (optional)

After the first launch you can edit
`BepInEx/config/com.crystalmods.redlaserlasgun.cfg` to change the beam **width**,
**glow**, **colour**, **duration**, or turn off **HideBolt** to keep the bolt too.

## Compatibility

Works alongside **The Great Crusade**, **Traditional Chinese Localization**, and
**Lasgun Recolored** with no conflicts (it only adds a plugin, no asset edits).
